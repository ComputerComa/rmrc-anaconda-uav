# RMRC Anaconda UAV

This repository documents the planning, integration, and development of an ArduPilot-based RMRC Anaconda fixed-wing UAV platform.

The project focuses on a modular avionics architecture built around a Pixhawk 6X, companion-computer integration, redundant communications, and support for advanced payloads and sensors.

Long-term goals include reliable autonomous operation, EO/IR payload integration, computer vision, precision navigation, and a maintainable platform that can be expanded over time.

Project documentation, BOMs, interface notes, and integration work will be kept here as the build develops.
